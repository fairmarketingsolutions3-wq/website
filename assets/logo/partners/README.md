# Partner logos

Both partner logos are in place. To replace one, overwrite the file using the
exact name below; the panel picks it up automatically and no HTML change is
needed.

| Partner           | Filename                    | Sits on          |
| ----------------- | --------------------------- | ---------------- |
| Rijk Zwaan        | `rijk-zwaan.png`            | Deep green panel |
| Holland Greentech | `holland-greentech.png`     | White card       |

Both were supplied as white artwork on black. The black was keyed to
transparency, so Rijk Zwaan's mark sits directly on the deep green panel,
and Holland Greentech's is backed by a deep green tile to read on its white
card.

Guidance:

- PNG with a transparent background.
- Supply roughly 500 x 160 px or larger; the logo is scaled to fit its slot
  and never cropped.
- A partner without a file here simply shows the name on its own. The slot is
  removed at runtime, so a missing logo never leaves a broken image.
