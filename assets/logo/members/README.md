# Member farm logos

Drop each founding farm's logo in this folder using the exact filename below.
The card picks it up automatically; no HTML change is needed.

| Farm                | Filename                   |
| ------------------- | -------------------------- |
| Fair Farms          | `fair-farms.png`           |
| Iringa Agro Fresh   | `iringa-agro-fresh.png`    |
| Pinerjo Smart Farm  | `pinerjo-smart-farm.png`   |
| She Farms           | `she-farms.png`            |
| Nahdi Youth Farm    | `nahdi-youth-farm.png`     |

Guidance:

- PNG with a transparent background reads best against the white card.
- The slot is 92 x 46 px on screen, so supply roughly 276 x 138 px (3x) or
  larger. The logo is scaled to fit inside the slot, never cropped.
- Any farm without a file here simply shows no logo. The slot is removed at
  runtime, so a missing logo never leaves a broken image on the card.
